# 캐릭터 일러스트

이 폴더에 아래 4개 파일을 넣으면 앱 전체(홈 카드 / 선택 화면 / 상담 도입부 / 배경)에
자동으로 반영됩니다. 파일이 없으면 캐릭터 색 그라디언트로 조용히 대체됩니다.

```
hari.png    하리  · 로즈
doyun.png   도윤  · 앰버
mio.png     미오  · 라벤더
jay.png     제이  · 민트
```

- 권장 비율: 9:16 세로 (720×1280 이상)
- 얼굴은 위쪽 1/3, 아래쪽은 이름·대사가 올라가므로 비워두는 구도가 좋습니다.
- 생성된 원본을 받으려면: `node scripts/fetch-art.mjs`

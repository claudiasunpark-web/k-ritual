# K-레벨: 영어원서 지수를 한국 아이 기준으로

AR, 렉사일, 글밥, 미국 학년은 서로 다른 잣대라 엄마들이 헷갈려한다.
K-레벨은 이걸 **"우리 아이가 지금 어디쯤이고, 이 책을 혼자 읽을 수 있나"** 한 가지 질문으로 번역한다.

> 기준 아이: 한국에서 영어를 외국어로 배우고, 파닉스를 뗀 뒤 **하루 20~30분 영어책을 꾸준히 읽는** 아이.
> "파닉스 후 개월 수"는 이 가정 위의 출발값이다. 앱 사용자 읽기 기록이 쌓이면 다시 보정한다.

## 단계표

| K-레벨 | AR | 렉사일(근사) | 파닉스 후 | 아이 모습 | 책 형태 | 글밥 | 권당 단어 수 |
|---|---|---|---|---|---|---|---|
| **0** 귀 열기 | — | — | 파닉스 전 | 엄마가 읽어줘요 | 그림책 | 글밥 상관없음 (읽어주기용) | — |
| **1** 첫 글자 | 0.1–1.0 | BR–150L | 파닉스 중 | 한 단어씩 짚으며 읽어요 | 파닉스북·리더스북 | 페이지당 한 줄, 같은 문장 반복 | ~150 |
| **2** 막 뗀 파닉스 | 1.0–1.5 | 150–300L | 0–3개월 | 소리 내어 혼자 읽어요 | 리더스북 | 페이지당 1~2문장, 그림이 대부분 | 100–500 |
| **3** 리더스 독립 | 1.5–2.0 | 300–400L | 3–6개월 | 소리 내어 혼자 읽어요 | 리더스북 | 페이지당 2~4문장 | 300–1,500 |
| **4** 얼리챕터 입문 | 2.0–2.5 | 400–480L | 6–9개월 | 혼자 읽을 수 있어요 | 리더스북·얼리챕터북 | 짧은 문단, 그림이 절반 이상 | 1,000–4,000 |
| **5** 혼자 읽기 | 2.5–3.0 | 480–550L | 6–12개월 | 혼자 읽을 수 있어요 | 얼리챕터북 | 페이지 절반이 글, 그림은 2~3쪽에 한 번 | 3,000–8,000 |
| **6** 챕터북 | 3.0–3.5 | 550–620L | 1년–1년 반 | 속으로 술술 읽어요 | 챕터북 | 페이지가 글로 차 있음 | 6,000–15,000 |
| **7** 챕터북 몰입 | 3.5–4.0 | 620–690L | 1년 반–2년 | 속으로 술술 읽어요 | 챕터북 | 그림 거의 없음, 긴 문단과 대화 | 10,000–25,000 |
| **8** 소설 입문 | 4.0–5.0 | 690–810L | 2–3년 | 속으로 술술 읽어요 | 소설 | 그림 없음, 빽빽한 글 | 20,000–50,000 |
| **9** 소설 독립 | 5.0–6.0 | 810–910L | 3–4년 | 속으로 술술 읽어요 | 소설 | 두꺼운 소설 | 40,000–90,000 |
| **10** 상급 독서 | 6.0+ | 910L+ | 4년+ | 속으로 술술 읽어요 | 소설 | 성인 소설에 가까운 글밥 | 50,000+ |

각 레벨의 "아이가 하는 모습", "엄마 역할", 대표 시리즈는 `src/levels/levels.ts`에 있다.

## 지수 번역 규칙

| 원래 지수 | 엄마에게 보여주는 말 |
|---|---|
| AR 2.5 | 미국 원어민 2학년 5개월째 아이가 혼자 읽는 수준이에요. **한국 아이 학년과는 상관없어요.** |
| 렉사일 `AD` | 엄마가 읽어주는 책. 지수가 높아도 '듣기 책'이라 아이 읽기 레벨과 비교하지 않는다 |
| 렉사일 `BR` | 처음 읽기 시작한 아이용 (0L보다 쉬움) |
| 렉사일 `GN` | 그래픽노블. 그림이 도와줘서 한 단계 쉽게 느껴질 수 있다 |
| 렉사일 `HL` | 지수는 낮지만 내용은 큰 아이용 |
| AR IL `LG/MG/MG+/UG` | 내용 적정 나이: 유치원~초3 / 초4~중2 / 초6+ / 중3+ |
| 미국 학년 | 한국 학년으로 환산 (K = 7세, 7학년 = 중1) |

## 우리 아이에게 맞나? (아이 레벨 대비 책 레벨)

| 차이 | 판정 | 쓰임 |
|---|---|---|
| -1 이하 | 술술 | 다독·자신감 쌓기 |
| 0 | 딱 맞음 | 혼자 읽기 |
| +1 | 도전 | 엄마와 함께, 오디오북과 같이 |
| +2 이상 | 어려움 | 읽어주거나 아껴두기 |
| `AD` 그림책 | 읽어주기 | 레벨과 별개 |

**한국 아이 특유의 함정 두 가지를 경고로 띄운다**
1. **실력은 되는데 내용이 성숙한 책**: 7살이 AR 5를 읽을 수 있어도 IL이 MG·UG면 경고.
2. **AR과 렉사일이 엇갈리는 책**: 두 지수가 2레벨 이상 다르면 "아이 반응 우선" 경고.

## 판정 순서

AR → 렉사일(근사 환산) → 권당 단어 수. AR을 먼저 보는 이유: 한국 엄마들이 가장 많이 쓰고, 학년 단위라 설명하기 쉽다.

# 추천 묶음과 쿠팡 구매

- **상황별**(잠자리, 새 학기, 화난 날, 영어 거부, 방학 시리즈): 직접 고른 목록
- **테마별 / 레벨별 / 문학상별**(칼데콧·뉴베리·가이젤): 카탈로그 데이터에서 자동 생성
- **한 권 사기**: 책마다 쿠팡 링크
- **묶음 전체 사기**: 이미 가진 책은 빼고, 한 권씩 쿠팡 페이지를 열어 담는 체크리스트.
  쿠팡은 외부에서 여러 상품을 한 번에 장바구니에 담는 기능을 열어두지 않아서 이 방식이 현실적인 최선이다.

## 내 실적으로 잡히는 링크 넣기

링크는 `src/catalog/coupang-links.json` 한 파일에서 관리한다. 링크 우선순위는
**내 파트너스 링크 → 쿠팡 상품 페이지 → 쿠팡 검색 결과**이고, 파트너스 링크만 내 실적으로 잡힌다.

**방법 1. 직접 붙여넣기 (API 키 없이 바로)**
쿠팡 파트너스 > 링크 생성에서 만든 링크를 책 id에 붙인다.

```json
{
  "charlottes-web": { "partnersUrl": "https://link.coupang.com/a/xxxxxx", "priceKrw": 9800 }
}
```

**방법 2. 파트너스 Open API로 한 번에**
쿠팡 파트너스 > 추가기능 > Open API에서 키를 받은 뒤:

```sh
COUPANG_ACCESS_KEY=... COUPANG_SECRET_KEY=... node scripts/fill-coupang-links.ts --dry-run   # 미리보기
COUPANG_ACCESS_KEY=... COUPANG_SECRET_KEY=... node scripts/fill-coupang-links.ts             # 저장
```

자동 매칭은 다른 판본이나 번역본을 고를 수 있으니 `matchedName`을 꼭 확인한다.
검색 API는 호출 횟수 제한이 있어서, 막히면 찾은 데까지 저장하고 멈춘다. 다시 돌리면 이어서 한다.

**파트너스 링크를 쓰는 화면에는 반드시 고지 문구를 표시한다** (`COUPANG_PARTNERS_DISCLOSURE`):
> 이 서비스는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

API 키(특히 시크릿 키)는 앱에 넣지 말고 서버에서만 쓴다.

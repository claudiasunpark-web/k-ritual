# 카탈로그 시트 사용법

책 목록은 구글 시트 두 장에서 관리한다. 앱은 이 시트를 `data/books.csv`, `data/series.csv`로 가져와서 쓴다.

- **낱권 시트**: 책 한 권에 한 줄 (문학상 수상작, 대표 그림책 등)
- **시리즈 시트**: 시리즈 하나에 한 줄 (Magic Tree House, Elephant & Piggie 등)

## 새 책 넣기

1. 시트 맨 아래 줄에 제목, 저자부터 적는다. **id는 비워두면 제목으로 자동으로 만들어진다.**
2. 아는 칸만 채운다. 빈칸이 있어도 괜찮다.
3. 지수(AR·렉사일·IL·레벨)를 확인했으면 `지수확인`에 Y. 아니면 N으로 두면 화면에 **근사**가 붙는다.
4. 다 고쳤으면 아래 "앱에 반영하기"를 한다.

## 칸 설명

| 칸 | 적는 법 | 예 |
|---|---|---|
| id | 비워두면 자동. 한 번 정하면 바꾸지 않기 (아이별 "집에 있어요" 기록이 id에 묶여 있음) | `charlottes-web` |
| 제목 / 시리즈명 | 영어 원제 | `Charlotte's Web` |
| 저자 | | `E. B. White` |
| 유형 | 그림책, 파닉스북, 리더스북, 얼리챕터북, 챕터북, 소설, 그래픽노블 | `소설` |
| 시리즈 (낱권만) | 속한 시리즈명 | `Magic Tree House` |
| 권수 (시리즈만) | 대략 | `37` |
| AR / AR최소·AR최대 | 숫자. 시리즈는 첫 권~마지막 권 범위 | `4.4` |
| 렉사일 (낱권만) | 코드 포함 그대로 | `680L`, `AD520L`, `GN390L` |
| IL | 내용 적정 나이. LG, MG, MG+, UG | `MG` |
| 레벨 | AR을 모를 때만 K-레벨(0~10)을 직접 | `2` |
| 읽어주기 | 엄마가 읽어주는 그림책이면 Y | `Y` |
| 지수확인 | 지수를 ARBookFind 등에서 확인했으면 Y | `N` |
| 테마 | 여러 개는 `;`로 구분 | `동물; 우정` |
| 상황 | 상황별 묶음. 여러 개는 `;` | `잠자리; 새 학기` |
| 문학상 (낱권만) | `상 이름 연도 대상/아너`, 여러 개는 `;` | `뉴베리 1953 아너` |
| 쿠팡링크 | 내 파트너스 링크 | `https://link.coupang.com/a/...` |
| 가격 | 원, 숫자만 | `9800` |
| 메모 | 자유롭게 (화면에는 안 나옴) | |
| 표지 (선택) | 표지 이미지 주소. 열이 없어도 됨. 비어 있으면 레벨 색 표지 | `https://...jpg` |

**시리즈 낱권:** 낱권의 `시리즈` 칸을 시리즈 시트의 `시리즈명`과 똑같이 적으면, 비어 있는 유형·테마·IL·레벨을 시리즈에서 이어받는다.
레벨은 시리즈의 AR최소 기준 근사값이 된다. 제목 위에는 "시리즈명 시리즈 (총 n권)"이 표시된다.

**레벨이 정해지는 순서:** 읽어주기 Y → 레벨 0 / AR → 렉사일 → 레벨 칸 / 아무것도 없으면 화면에 "레벨 확인 중".

**상황 칸에 쓰는 값:** `잠자리`, `새 학기`, `화난 날`, `영어 거부`, `시리즈 몰입`은 화면에 정해진 제목·설명이 나온다.
새 값(예: `여름방학`)을 적으면 그 이름으로 새 묶음이 생긴다.

## 앱에 반영하기

시트 두 장을 **공유 → 링크가 있는 모든 사용자: 뷰어**로 바꾼 뒤:

```sh
npm run import-sheet -- "<낱권 시트 주소>" "<시리즈 시트 주소>"
npm run build
```

틀린 칸이 있으면 아무것도 바꾸지 않고 "낱권 12행 'AR': 0~13 사이 숫자여야 해요"처럼 고칠 곳을 알려준다.

## 문제집 시트 (data/workbooks.csv)

보캡·그래머·파닉스 문제집을 K-레벨 범위로 적으면, "우리 아이 지금" 아래 **함께 풀 문제집**에 나온다.

| 칸 | 적는 법 |
|---|---|
| 제목 / 출판사 | |
| 종류 | 파닉스, 사이트워드, 보캡, 그래머 |
| 레벨최소 / 레벨최대 | 0~10. 읽기 레벨보다 살짝 쉽게 잡는다 |
| 설명 | 엄마에게 보여줄 한 줄 |
| 쿠팡링크 | 내 파트너스 링크 (비어 있으면 쿠팡 검색) |

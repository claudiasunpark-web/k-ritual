# K-RITUAL · 심야 연애 상담소 🔮

만화(웹툰) 느낌의 캐릭터와 **스토리식 대화**로 진행되는 연애 상담 웹앱입니다.
사주(오행) 기반 궁합 해석 + 이번 주 처방전까지 한 번에 나옵니다.

- 프레임워크 없음 (바닐라 JS + ES 모듈), 빌드 단계 없음
- 의존성 0개 — `node server.js` 한 줄로 실행
- **API 키 없이도 완전히 동작**(스토리 모드). 키를 넣으면 AI 상담 모드로 업그레이드

## 실행

```bash
npm start            # → http://localhost:5173
```

AI 상담 모드를 켜려면:

```bash
cp .env.example .env         # ANTHROPIC_API_KEY 를 채운 뒤
export $(cat .env | xargs) && npm start
```

키가 있으면 상담사 대사가 Claude API로 생성되고, 없으면 내장 스토리 엔진이 대신 답합니다.
(상단 우측에 `AI 상담 모드` / `스토리 모드` 로 표시)

## 화면 흐름

```
홈 → 온보딩 5단계(입력) → 캐릭터 선택 → 스토리 상담 → 처방전 → (더 물어보기 / 기록 보관)
```

## 사용자에게 받는 입력 (= 상담 품질을 결정하는 재료)

### 1. 나 (필수)

| 입력 | 필수 | 어디에 쓰이나 |
|---|---|---|
| 닉네임 | ✅ | 상담사가 부르는 호칭, 결과 시드 |
| 생년월일 | ✅ | 천간·지지 → 띠·오행(일간) 계산, 궁합 점수 |
| 태어난 시간 | — | 확장용(시주). 현재는 보관만 |
| MBTI | — | 궁합 보정(N/S·F/T 일치 가산) |

### 2. 관계 단계 (필수, 택 1)

`짝사랑 / 썸 / 연애 중 / 권태기 / 이별·재회 / 소개팅·앱`
→ **이 값이 스토리 챕터를 통째로 바꿉니다.** (질문·선택지·미션·금지사항 전부 분기)

### 3. 상대 (전부 선택 입력)

| 입력 | 쓰임 |
|---|---|
| 호칭 | 대사에 그대로 등장 |
| 생년월일 | 삼합/육충 + 오행 상생·상극 → 궁합 점수의 핵심 |
| MBTI | 궁합 보정 |
| 알고 지낸 기간 | AI 모드 컨텍스트 |
| 연락 빈도 (5단계) | 궁합 점수 보정(+6 ~ -12), 조언 방향 |

### 4. 고민 (필수 1개 이상, 최대 3개)

`상대 마음 / 연락·답장 / 고백 타이밍 / 싸움 / 불안·질투 / 미래·결혼 / 자존감 / 헤어질지`
→ 처방전의 "지금 흐름 읽기" 항목이 이 선택으로 구성됩니다.

### 5. 상황 서술 (선택, 자유 텍스트)

길게 쓸수록 좋습니다. AI 모드에서는 시스템 프롬프트에 그대로 들어가고,
스토리 모드에서도 상담사가 인용해 되비춰 줍니다.

### 6. 상담 중 입력

- **선택지**: 각 선택은 `push(적극) / hold(관망) / care(자기돌봄)` 점수를 가지며,
  합산 결과가 처방전의 **연애 성향(돌진형/관망형/회복형)** 이 됩니다.
- **자유 서술 답변**: 키워드로 고민 카테고리를 추정해 답변이 달라집니다.

> 모든 입력은 **브라우저 localStorage에만** 저장됩니다. 서버로 전송되는 건
> AI 모드에서의 대화 내용뿐이고, 그것도 저장하지 않습니다.

## 출력 (처방전)

- 궁합 점수(28~97) + 등급, 그렇게 나온 이유(삼합/충, 오행 상생·상극, 연락 흐름)
- 두 사람의 오행 카드
- 연애 성향 진단 (지켜야 할 것 / 조심할 것)
- 고민별 "지금 흐름 읽기" + 실행 제안
- 이번 주 미션 3개 / 절대 하지 말 것 / 요일별 기류 / 오늘의 부적
- 요약 텍스트 복사, 최근 20건 기록 보관

## 구조

```
server.js              정적 서빙 + /api/chat (Claude 프록시) + /api/health
public/
  index.html
  styles.css           웹툰 패널·하프톤·말풍선 스타일
  app.js               화면 전환, 스토리 진행, 리포트 렌더
  engine.js            사주 계산 / 궁합 / 리포트 생성 / AI 브릿지
  data/
    characters.js      상담사 4명 (말투·색·페르소나)
    scenarios.js       단계별 챕터, 고민별 해석, 미션, 부적
```

## 커스터마이징

- **캐릭터 추가**: `public/data/characters.js`에 객체 하나 추가 → 자동으로 선택 화면에 노출.
  얼굴은 SVG로 그려지며, 일러스트가 있으면 `avatarSVG()` 대신 `<img>`로 교체하면 됩니다.
- **질문/스토리 수정**: `public/data/scenarios.js`의 `CHAPTERS`만 고치면 됩니다.
- **모델 변경**: `CLAUDE_MODEL` 환경변수.

## 주의

연애 상담 콘텐츠는 엔터테인먼트 목적입니다. 폭력·스토킹·자해 등 위험 신호가 있는
상황에서는 전문기관 상담을 안내하도록 AI 프롬프트에 규칙이 들어가 있습니다.

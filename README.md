# K-Ritual Classes: Shopify 클래스 판매 테마

원데이 클래스, 정규 클래스, 온라인 클래스를 판매하는 **Shopify 테마**입니다.
Walton Learning 같은 "powered by Shopify" 사이트와 같은 방식으로, **클래스 하나 = Shopify 상품 하나**, **수업 일정 하나 = 상품 옵션(Variant) 하나**로 운영합니다.

```
assets/     CSS, JS
config/     테마 전체 설정 (색상, 글꼴 등)
layout/     공통 HTML 틀
locales/    화면 문구 (영어 기본 + 한국어)
sections/   편집기에서 끌어다 놓는 블록들
snippets/   재사용 조각 (클래스 카드, 가격 등)
templates/  페이지별 구성 (홈, 클래스 상세, 장바구니 등)
```

## 포함된 기능

| 페이지 | 구성 |
|---|---|
| 홈 | 메인 배너, 클래스 목록, 수강 혜택, 강사 소개, 수강 후기, FAQ, 단체 예약 안내 |
| 클래스 상세 | 사진 갤러리, 가격, 클래스 정보(시간/난이도/방식/인원), **일정 선택 카드**, **남은 좌석 표시**, 수강 인원 선택, 신청 버튼, Shop Pay 바로결제, 커리큘럼, 환불 규정, FAQ, 다른 클래스 추천 |
| 기타 | 클래스 컬렉션, 장바구니(강사에게 메모), 검색, 문의 폼, 블로그, 오픈 준비중 페이지, 404 |

모든 문구, 사진, 색상, 글꼴은 Shopify 테마 편집기에서 코드 없이 바꿀 수 있습니다.

---

## 1단계: Shopify 가입

1. https://www.shopify.com 에서 무료 체험으로 가입합니다.
2. **설정 → 스토어 세부 정보**에서 통화와 시간대를 정합니다.
3. **설정 → 결제**에서 Shopify Payments(또는 PayPal 등)를 연결합니다.

## 2단계: 테마 올리기 (둘 중 하나)

**방법 A: GitHub 연결 (추천, 코드 수정이 자동 반영됨)**
1. 온라인 스토어 → 테마 → 테마 추가 → **GitHub에서 연결**
2. `claudiasunpark-web/k-ritual` 저장소와 브랜치를 선택합니다.

**방법 B: ZIP 업로드**
1. 이 저장소 폴더에서 아래 명령으로 zip을 만듭니다.
   ```bash
   zip -r k-ritual-theme.zip assets config layout locales sections snippets templates
   ```
2. 온라인 스토어 → 테마 → 테마 추가 → **zip 파일 업로드**
3. 업로드된 테마에서 **게시**를 누릅니다.

## 3단계: 클래스(상품) 등록

**상품 → 상품 추가**에서:

- **제목**: 클래스 이름 (예: "전통 다도 원데이 클래스")
- **설명**: 클래스 소개
- **사진**: 첫 번째 사진이 대표 이미지가 됩니다
- **실물 상품 체크 해제**: "배송이 필요한 실물 상품입니다"를 끄면 결제 때 배송지를 묻지 않습니다
- **옵션(Variants)**: 옵션 이름을 `일정`으로 하고 값에 수업 날짜를 넣습니다
  - 예: `10월 12일 (토) 오후 2시`, `10월 19일 (토) 오후 2시`
  - 일정마다 가격을 다르게 할 수도 있습니다
- **재고 추적 켜기 + 재고 수량 = 정원**: 예를 들어 정원이 12명이면 재고를 12로 둡니다.
  - "품절 시 계속 판매" 옵션을 **끄면** 자리가 다 찼을 때 자동으로 "마감"이 표시됩니다
  - 남은 자리가 5석 이하가 되면 "남은 자리 N석"이 강조 표시됩니다 (기준은 테마 설정에서 변경)
- **상품 유형**: 예) "원데이 클래스". 상세 페이지 제목 위에 작게 표시됩니다

## 4단계: 클래스 정보 필드 만들기 (메타필드)

클래스마다 다른 **수업 시간 / 난이도 / 수업 방식 / 정원 / 시작일**을 보여주려면
**설정 → 사용자 지정 데이터 → 상품 → 정의 추가**에서 아래 필드를 만듭니다.

| 이름 | 네임스페이스와 키 | 유형 | 예시 |
|---|---|---|---|
| 수업 시간 | `course.duration` | 한 줄 텍스트 | 2시간 |
| 난이도 | `course.level` | 한 줄 텍스트 | 입문 |
| 수업 방식 | `course.format` | 한 줄 텍스트 | 오프라인 (강남) / 온라인 Zoom |
| 정원 | `course.class_size` | 한 줄 텍스트 | 최대 8명 |
| 시작일 | `course.start_date` | 날짜 | 2026-10-12 |

만들고 나면 각 상품 편집 화면 하단에 입력 칸이 생깁니다.
값이 비어 있는 항목은 화면에 표시되지 않습니다.

## 5단계: 메뉴, 페이지, 컬렉션

- **컬렉션**: 상품 → 컬렉션에서 "원데이 클래스", "정규 과정", "온라인" 등으로 묶습니다
- **메뉴**: 온라인 스토어 → 탐색 → `main-menu`에 "클래스", "소개", "문의" 등을 추가합니다
- **문의 페이지**: 온라인 스토어 → 페이지 → 페이지 추가 → 템플릿을 `page.contact`로 선택합니다
- **환불 정책**: 설정 → 정책에서 작성하면 결제 화면에 자동으로 링크됩니다

## 6단계: 디자인 편집

온라인 스토어 → 테마 → **사용자 지정**에서:
- 섹션을 추가, 삭제하거나 순서를 바꿉니다 (홈, 클래스 상세 모두)
- 왼쪽 아래 **테마 설정**에서 색상, 글꼴, 모서리 둥글기를 바꿉니다
- 클래스마다 커리큘럼이 다르면 상세 페이지 템플릿을 복제해서(예: `product.tea-ceremony`) 상품별로 지정합니다

## 언어

화면 문구는 영어(기본)와 한국어가 들어 있습니다.
**설정 → 언어**에서 한국어를 기본 언어로 바꾸면 버튼과 안내 문구가 한국어로 표시됩니다.
편집기에서 입력한 제목과 설명은 입력한 언어 그대로 나옵니다.

## 자주 쓰는 추가 기능 (Shopify 앱)

| 필요한 기능 | 방법 |
|---|---|
| 온라인 클래스 Zoom 링크 전달 | 설정 → 알림 → "주문 확인" 이메일에 안내 문구 추가, 또는 상품 설명에 "결제 후 이메일로 발송" 명시 |
| 녹화 강의 / PDF 교재 판매 | Shopify의 무료 앱 **Digital Downloads**로 결제 후 파일 자동 발송 |
| 달력형 예약, 자동 리마인더 | Shopify 앱 스토어에서 "booking" / "appointment" 앱 검색 |
| 수강권 선물 | 상품 → 기프트 카드 (기본 기능) |
| 할인 코드, 얼리버드 | 할인 메뉴 (기본 기능) |

## 개발자용

```bash
npm i -g @shopify/cli
shopify theme dev --store=<내스토어>.myshopify.com   # 로컬 미리보기
shopify theme check                                  # 코드 검사
shopify theme push                                   # 스토어에 업로드
```
